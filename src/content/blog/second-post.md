# Getting Started with Astro

Astro makes it easy to build fast, content-focused websites.

## Quick Start

1. Create a new project with `npm create astro@latest`
2. Start the dev server with `npm run dev`
3. Build for production with `npm run build`

## Content Collections

Astro's content collections make it easy to manage your blog posts, documentation, or any other content with type-safe frontmatter.

Happy coding!
